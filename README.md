# Blue Babylon Capital AB

Webbplats för Blue Babylon Capital AB och Börstjänarfolket 2013 AB.

## Struktur

- `index.html` – Blue Babylons startsida
- `filosofi.html` – investeringsfilosofi
- `resultat.html` – aktiekurs och track record
- `om-oss.html` – förvaltning och ledning
- `nyheter.html` – träffar, investerarbrev och investerarmöten
- `investera.html` – intresseanmälan
- `riskinformation.html` – samlad riskinformation
- `btfolket/` – Börstjänarfolkets separata webbplats

## Publicering

Webbplatsen publiceras genom GitHub Pages.
